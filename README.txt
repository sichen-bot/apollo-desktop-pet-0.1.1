阿波罗桌宠 0.1.1 分件说明

这不是已经在 Windows 上运行成功的程序包证明，只是把原来那一个 25.4 MB 的安装包拆成两个普通 ZIP，方便聊天附件发送。不是 .z01 / .z02 分卷压缩。

两个压缩包：
- Apollo-0.1.1-part1-program.zip　程序、依赖和动作清单（manifest）
- Apollo-0.1.1-part2-assets.zip　待机和摸头的 96 张动作帧

请按下面做：
1. 新建一个空文件夹，例如「阿波罗桌宠-0.1.1」。
2. 把 part1 解压到这个文件夹。
3. 再把 part2 解压到同一个文件夹。不要解压到两个不同的目录。
4. 解压完成后应看到子文件夹 win-x64-fd-011，其中有 Apollo.DesktopPet.exe。
5. 运行前需要先安装官方免费的「.NET 10 Desktop Runtime 10.0.15，Windows x64」。本包不会自动安装运行库，也不包含付费内容。
6. 两个包都解压后，才能完整播放待机循环和摸头动作。只解压 part1 时没有那 96 张动作帧。

请不要改系统设置、不要加入开机启动。解压时如遇到错误，请保留完整报错文字或截图。
